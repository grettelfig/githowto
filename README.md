# GitHowTo projekti kokkuvõte

## Mis projektiga on tegemist?
GitHowTo projekt, on algajatele mõeldud õpetus, mille abil saab õppija selgeks kõik alusteadmised ja saab parema mõistmise Git'i kohta.
GitHowTo õpetuse leiad siit https://githowto.com/

## Mida selle projekti käigul õppisin?
Selle projekti käigul õppisin:
* kuidas Git töötab
* missugused käsud eksisteerivad
* kuidas lahendada probleeme ja parandada vigu
* millised on Git'i baasteadmised

## Milliseid Git käske kasutasin?
### Õppisin ja kasutasin paljusid käske.
Alguses panin paika enda nime ja e-posti.
```
git config --global user.name "Your Name"
git config --global user.email "your_email@whatever.com"
```

### Õppisin kõige tähtsama käsu ära, mida pean kasutama iga kord, kui teen mingisuguse muudatuse enda failile.
```
git add faili_nimi või .
git commit -m "muudatuse_selgitus_sõnumina"
```

### Õppisin veel, kuidas jälgida enda faili staatust. Kui midagi on valesti või commitimata, viskab see kohe probleemi ette.
```
git status
```
ja kuidas näha kõiki enda commite
```
git log
```
